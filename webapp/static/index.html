3 The USB key

Write the whole bundle (cert, key, CRL, connection info) onto a USB stick so you can carry it to the machine running your web client — then load it back here.

4 Install the cert on the printer

Sends security.app_cert_install over MQTT (8883) on your LAN. No Bambu cloud, no LAN-only mode. The printer trusts what it installs — the cert and CRL share an issuer, so it lands cleanly.
